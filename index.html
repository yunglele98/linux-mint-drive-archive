Linux Mint Drive Archive

A personal desktop OAuth application used with rclone to archive files from a Linux Mint computer to the owner's Google Drive.

This application is for the owner's personal use. It is not a public backup service and does not offer account registration.

How it works

The owner authorizes rclone through Google's browser-based sign-in. Rclone runs locally and transfers files directly to Google Drive. Archive verification compares file sizes and checksums before any separately authorized removal of local originals.

The Google Drive permission permits viewing, creating, editing and deleting Drive files. The owner controls which rclone commands run and which files are accessed. The website itself cannot access Drive.
